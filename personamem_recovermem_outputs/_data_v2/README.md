# PersonaMem-v2: Towards Personalized Intelligence via Learning Implicit User Personas and Agentic Memory

#### 📅 We have now released [PersonaMem-v3](https://huggingface.co/datasets/bowen-upenn/PersonaMem-v3)!
#### 🚨 The paper is now released. View the full paper [here](https://www.arxiv.org/pdf/2512.06688) and codebase [here](https://github.com/bowen-upenn/PersonaMem-v2).

---

**Personalization is becoming the next milestone of artificial super-intelligence.** AI cannot always satisfy every user, especially on tasks with subjective goals, but personalization offers a path toward **pluralistic alignment**. **PersonaMem-v2** is the new state-of-the-art LLM-personalization dataset focusing on **implicit personas in LLMs**, where user–chatbot conversations implicitly indicate user preferences. For example, a user might **unintentionally** reveal a seasonal allergy in their email content **while only asking a chatbot to refine the wording of that email**. Our goal is to mimic realistic user personas and users' long-form conversation histories with chatbots, in order to study how well AI systems can memorize and infer these implicit signals and understand the users they are interacting with, and therefore **provide personalized responses** over time to enhance user experience.

- For questions, please reach out to Bowen Jiang (Lauren) at bwjiang@seas.upenn.edu, or submit an issue on [GitHub](https://github.com/bowen-upenn/PersonaMem-v2).

### ⚠️ Warning
**We strive to provide the best personalization benchmark for the open-source community.** However, please understand that all data are LLM-generated and we cannot manually verify every single sample. Although we have imposed multiple quality and safety filters, the dataset may still contain stereotypical biases or other harmful information. All sensitive or private user information has been pseudonymized and generated without real-world inputs, which may still coincidentally and unintentionally match real-world data.

## ✨ Key Features

### 🌍 1,000 Comprehensive and High-Quality Personas
- We cover almost all geographical locations, as well as racial and gender identities. 
- Each persona contains an **unfixed set of attributes**, but always includes:
  - Short persona descriptions from [PersonaHub](https://huggingface.co/datasets/proj-persona/PersonaHub)
  - Comprehensive demographic information
  - Work and education backgrounds  
  - Personal character traits
  - Conversation styles with the chatbot
  - Sensitive user information leaked in the contexts
  - **Mental and physcial health and medical backgrounds**
  - **Stereotypical, anti-stereotypical, and neutral user preferences**
- Within each persona, all user preferences are carefully curated to remove **repetition** and **contradictions**  

### 💬 Wide Coverage of Chatbot Use Cases
- Implicit user preferences are revealed across realistic daily tasks a user might talk to a chatbot, such as:
  - Writing improvement on emails and chat messages  
  - **Multilingual** translations  
  - **Multimodal** photo sharing and questioning  
  - Knowledge queries (e.g., *An AI beginner might ask ChatGPT 'What is layer norm in transformers?' and return to similar topics multiple times.*)  
  - Therapy consultations
  - Medical and health concerns

### 🔒 Privacy-Aware Design
- Users can request the chatbot **not to remember** certain preferences  
- All target answers avoid **sensitive or private user information**, even if the user has leaked such information in the history

### 🗂️ Other Features
- We distinguish between preferences that belong to the users **themselves** and those referring to **others**, such as questions from public math/coding benchmarks irrelevant to the current user's preferences.
- **Preference updates over time**  
- All conversation sections are **multi-turn** (2–5 turns)
- All user preferences and queries are marked with their **categories**.
- In total, we have **1,000** personas, **26,100** user preferences, conversation snippets, and Q&A pairs, **325** conversation topics, and **335** user query topics. 

### 🎯 Powered by GPT-5
- Every persona, preference, conversation snippet, and Q&A is generated by [**GPT-5**](https://platform.openai.com/docs/models/gpt-5-chat-latest) without the auto-router, in addition to a series of quality filtering processes to improve the data quality.

## 📂 Dataset Contents
### Core
- **`benchmark/text/benchmark.csv`**  
  Contains **5000 user queries** as our benchmark data. Each entry is associated with the link to its corresponding chat history file, the target answer, user preference, related conversation snippets, and additional metadata. **To run benchmark evaluation with long context, append the user_query to the end of its chat history.** Each context window is up to 32k or 128k tokens with only languages.

- **`benchmark/text/train.csv`**  
  Contains **18500 user queries** as our training data. It has the same data structure with `benchmark/text/benchmark.csv` but no overlap on `persona_id`.

- **`benchmark/text/val.csv`**  
  Contains **2600 user queries** as our validation data. It has the same data structure with `benchmark/text/benchmark.csv` but no overlap on `persona_id`.

- **`benchmark/multimodal/benchmark.csv`**  
  Contains **5000 user queries** as our benchmark data. It has the same data structure with `benchmark/text/benchmark.csv` but with both images and languages in chat histories.

- **`benchmark/multimodal/train.csv`**  
  Contains **19200 user queries** as our training data. It has the same data structure with `benchmark/multimodal/benchmark.csv` but no overlap on `persona_id`.

- **`benchmark/multimodal/val.csv`**  
  Contains **2110 user queries** as our validation data. It has the same data structure with `benchmark/multimodal/benchmark.csv` but no overlap on `persona_id`.

### Supplimentary
- **`data/raw_data/*.json`**  
  Contains **1,000 persona files**, each including full persona, user preferences, user–chatbot conversation snippet related to each preference, Q&A pairs, and other meta data.

- **`data/chat_history_32k/*.json`**  
  Contains **1,000 chat history files**, each paired with a corresponding persona file under `raw_data/`, mimcking the user–chatbot conversation history of that user, up to 32k tokens. All histories are text-only.

- **`data/chat_history_multimodal_32k/*.json`**  
  Contains **1,000 chat history files**, each paired with a corresponding persona file under `raw_data/`, mimcking the user–chatbot conversation history of that user, up to 32k tokens. Histories might contain base64-encoded images.

- **`data/chat_history_128k/*.json`**  
  Contains **1,000 chat history files**, each paired with a corresponding persona file under `raw_data/`, mimcking the user–chatbot conversation history of that user, up to 128k tokens. All histories are text-only.

- **`data/chat_history_multimodal_128k/*.json`**  
  Contains **1,000 chat history files**, each paired with a corresponding persona file under `raw_data/`, mimcking the user–chatbot conversation history of that user, up to 128k tokens. Histories might contain base64-encoded images.

- **`combined_irrelevant_data.json`**  
  Contains **1,545** user–chatbot conversation snippets **unrelated to any persona**. Each snippet can be multi-turn, focusing on mathematical and coding problems from public benchmarks, including but not limited to [GSM8K](https://huggingface.co/datasets/openai/gsm8k), [Omni-Math](https://huggingface.co/datasets/KbsdJames/Omni-MATH), and [BigCode-Bench](https://huggingface.co/datasets/bigcode/bigcodebench). We also simulated multi-round debugging interactions which can be used to fill up context windows.
